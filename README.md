# OSMION Works website

A responsive static website for OSMION Works.

## Files
- `index.html` — website content
- `styles.css` — visual styling
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the published website address after deployment.
